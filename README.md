Downloads Organizer Tool (Windows Only)

This tool assumes that you have the standard file path to your Downloads directory.
i.e. C:\Users\yourName\Downloads . Additionally, it will not work for back ups stored on OneDrive.

This tool will organize your Downloads folder by placing each file in your downloads in
newly created subdirectories. Those subdirectories are listed below:
1) Images
2) Documents
3) Installers
4) Audio
5) Video
6) Miscellaneous
